# Iris Flower Clustering using K-Means

## Project Overview
This project uses the K-Means clustering algorithm to group Iris flowers into three clusters based on their measurements.

## Dataset
The Iris dataset is loaded directly from Scikit-learn.

- Total Samples: 150
- Features: 4
- Clusters: 3

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Algorithms Used
- K-Means Clustering
- Principal Component Analysis (PCA)

## Project Workflow
1. Load the Iris dataset.
2. Explore and analyze the data.
3. Standardize the features.
4. Apply K-Means clustering.
5. Visualize the clusters.
6. Compare actual labels with predicted clusters.
7. Apply PCA for dimensionality reduction.
8. Evaluate using Silhouette Score.

## How to Run
1. Install the required libraries.
2. Open the Jupyter Notebook.
3. Run all cells sequentially.

## Outcome
Successfully implemented K-Means clustering to group Iris flowers and visualized the results using PCA.
